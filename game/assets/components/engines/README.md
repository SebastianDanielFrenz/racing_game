# Engine component images

Built-in imagegen product renders on transparent backgrounds: inline-four, inline-six,
single turbo and twin turbo. These illustrate the selected component layout; they are
not scans of manufacturer hardware or a promise of measured engine-bay fitment.
The two engines are authored compatible options for the fictional sedan chassis.
Car mass, collision geometry and the engine-bay mesh are currently retained on a swap.

Prompts: complete naturally aspirated inline-four / inline-six engines, distinct
four / six coil positions and intake runners; exactly one / two complete turbocharger
assemblies. Each uses a three-quarter studio product view, warm key and cool fill,
generous square framing, no logos, lettering, floor, car or background.

Turbo calibrations share a hardware image when hardware count is identical. Their
cards show count and charge-pressure target; no invented performance gain is shown.
